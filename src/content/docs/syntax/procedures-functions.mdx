Los procedimientos y funciones permiten organizar tu código en bloques reutilizables y modulares.

## Sub vs Function

### Sub - Procedimientos

Los `Sub` ejecutan acciones pero no devuelven valores.

<Code
  code={`Sub SaludarUsuario()
    ' Un Sub simple sin parámetros
    MsgBox "¡Hola! Bienvenido a VBA"
End Sub

Sub LimpiarRango()
' Sub que realiza una acción específica
Range("A1:D10").ClearContents
Range("A1").Value = "Datos limpiados"
End Sub`}
lang="VBA"
title="Sub básicos"
/>

### Function - Funciones

Las `Function` ejecutan cálculos y devuelven un valor.

<Code
  code={`Function CalcularIVA(precio As Double) As Double
    ' Una función que devuelve un valor
    CalcularIVA = precio * 0.21
End Function

Function ObtenerSaludo() As String
' Función simple que devuelve texto
ObtenerSaludo = "Buenos días"
End Function

' Usar las funciones
Sub EjemploUso()
Dim precioFinal As Double
Dim mensaje As String

    precioFinal = CalcularIVA(100)  ' Devuelve 21
    mensaje = ObtenerSaludo()       ' Devuelve "Buenos días"

    Range("A1").Value = precioFinal
    Range("A2").Value = mensaje

End Sub`}
lang="VBA"
title="Function básicas"
/>

<Aside type="tip">
  Usa **Sub** para acciones y **Function** para cálculos que necesitan devolver
  un resultado.
</Aside>

## Parámetros

### Parámetros Simples

<Code
  code={`Sub EscribirEnCelda(celda As String, valor As String)
    ' Sub con dos parámetros
    Range(celda).Value = valor
End Sub

Function Sumar(num1 As Double, num2 As Double) As Double
' Function con parámetros que devuelve resultado
Sumar = num1 + num2
End Function

' Usar procedimientos con parámetros
Sub Ejemplo()
EscribirEnCelda "A1", "Hola mundo"
EscribirEnCelda "B1", "VBA es genial"

    Dim resultado As Double
    resultado = Sumar(15, 25)  ' resultado = 40
    Range("C1").Value = resultado

End Sub`}
lang="VBA"
title="Parámetros básicos"
/>

### Parámetros Opcionales

<Code
  code={`Sub FormatearCelda(celda As String, texto As String, Optional color As Long = vbBlack)
    ' Parámetro color es opcional con valor por defecto
    With Range(celda)
        .Value = texto
        .Font.Color = color
    End With
End Sub

Function CalcularDescuento(precio As Double, Optional descuento As Double = 0.1) As Double
' Descuento por defecto del 10%
CalcularDescuento = precio \* (1 - descuento)
End Function

Sub EjemplosOpcionales()
' Usar sin parámetro opcional (usa el valor por defecto)
FormatearCelda "A1", "Texto normal" ' Color negro por defecto

    ' Usar con parámetro opcional
    FormatearCelda "A2", "Texto rojo", vbRed

    ' Función con y sin parámetro opcional
    Range("B1").Value = CalcularDescuento(100)      ' Descuento 10%
    Range("B2").Value = CalcularDescuento(100, 0.2) ' Descuento 20%

End Sub`}
lang="VBA"
title="Parámetros opcionales"
/>

### ByRef vs ByVal

<CardGrid>
  <Card title="ByRef (Por Referencia)" icon="document">
    Modifica la variable original
    <Badge text="Por defecto en VBA" variant="caution" />
  </Card>

  <Card title="ByVal (Por Valor)" icon="document">
    Crea una copia, no modifica el original
    <Badge text="Más seguro" variant="success" />
  </Card>
</CardGrid>

<Code
  code={`Sub EjemploByRef(ByRef numero As Integer)
    ' ByRef: modifica la variable original
    numero = numero * 2
End Sub

Sub EjemploByVal(ByVal numero As Integer)
' ByVal: no modifica la variable original
numero = numero \* 2
End Sub

Sub ProbarParametros()
Dim valor1 As Integer
Dim valor2 As Integer

    valor1 = 10
    valor2 = 10

    EjemploByRef valor1  ' valor1 ahora es 20 (modificado)
    EjemploByVal valor2  ' valor2 sigue siendo 10 (no modificado)

    Range("A1").Value = "ByRef: " & valor1  ' 20
    Range("A2").Value = "ByVal: " & valor2  ' 10

End Sub`}
lang="VBA"
title="ByRef vs ByVal"
/>

<Aside type="caution">
  Por defecto, VBA usa **ByRef**. Especifica **ByVal** cuando no quieras
  modificar la variable original.
</Aside>

## Ámbito de Variables

### Variables Locales

<Code
  code={`Sub VariablesLocales()
    Dim nombre As String  ' Solo existe dentro de este Sub
    nombre = "Juan"
    MsgBox nombre
End Sub  ' La variable 'nombre' desaparece aquí

Sub OtroSub()
' Esta línea causaría error porque 'nombre' no existe aquí
' MsgBox nombre ' ERROR
End Sub`}
lang="VBA"
title="Variables locales"
/>

### Variables de Módulo

<Code
  code={`' Al inicio del módulo, antes de cualquier Sub/Function
Dim contadorGlobal As Integer  ' Variable a nivel de módulo

Sub IncrementarContador()
contadorGlobal = contadorGlobal + 1
Range("A1").Value = "Contador: " & contadorGlobal
End Sub

Sub MostrarContador()
' Puede acceder a contadorGlobal porque está en el mismo módulo
MsgBox "El contador actual es: " & contadorGlobal
End Sub`}
lang="VBA"

## Funciones Recursivas

<Code
  code={`Function Factorial(n As Integer) As Long
    ' Función que se llama a sí misma
    If n <= 1 Then
        Factorial = 1
    Else
        Factorial = n * Factorial(n - 1)
    End If
End Function

Function Fibonacci(n As Integer) As Long
' Secuencia de Fibonacci recursiva
If n <= 2 Then
Fibonacci = 1
Else
Fibonacci = Fibonacci(n - 1) + Fibonacci(n - 2)
End If
End Function

Sub EjemplosRecursion()
Range("A1").Value = "5! = " & Factorial(5) ' 120
Range("A2").Value = "Fib(8) = " & Fibonacci(8) ' 21
End Sub`}
lang="VBA"
title="Funciones recursivas"
/>

<Aside type="caution">
  Las funciones recursivas pueden ser lentas y consumir mucha memoria. Úsalas
  con cuidado.
</Aside>

## Funciones con Rangos

<Code
  code={`Function SumarRango(rango As Range) As Double
    ' Función que recibe un rango como parámetro
    Dim celda As Range
    Dim suma As Double
    
    suma = 0
    For Each celda In rango
        If IsNumeric(celda.Value) Then
            suma = suma + celda.Value
        End If
    Next celda
    
    SumarRango = suma
End Function

Function ContarCeldasConTexto(rango As Range, texto As String) As Integer
Dim celda As Range
Dim contador As Integer

    contador = 0
    For Each celda In rango
        If celda.Value = texto Then
            contador = contador + 1
        End If
    Next celda

    ContarCeldasConTexto = contador

End Function

Sub UsarFuncionesConRangos()
Dim miRango As Range
Set miRango = Range("A1:A10")

    Range("B1").Value = "Suma: " & SumarRango(miRango)
    Range("B2").Value = "Celdas 'Sí': " & ContarCeldasConTexto(miRango, "Sí")

End Sub`}
lang="VBA"
title="Funciones con rangos"
/>

## Buenas Prácticas

<Steps>

1. **Nombres descriptivos**

   ```vba
   ' Bueno
   Sub CalcularNomina()
   Function ObtenerPrecioConDescuento() As Double

   ' Malo
   Sub Calculo()
   Function GetPCD() As Double
   ```

2. **Documentar parámetros**

   ```vba
   Function CalcularIntereses(capital As Double, tasa As Double, tiempo As Integer) As Double
       ' capital: monto inicial en pesos
       ' tasa: tasa anual (0.05 para 5%)
       ' tiempo: años
       CalcularIntereses = capital * tasa * tiempo
   End Function
   ```

3. **Validar entrada**

   ```vba
   Function DividirSeguro(dividendo As Double, divisor As Double) As Double
       If divisor = 0 Then
           MsgBox "Error: No se puede dividir por cero"
           DividirSeguro = 0
           Exit Function
       End If
       DividirSeguro = dividendo / divisor
   End Function
   ```

4. **Usar tipos específicos**

   ```vba
   ' Específico y claro
   Function ContarFilas(hoja As Worksheet) As Long

   ' Demasiado genérico
   Function ContarFilas(obj As Object) As Variant
   ```

</Steps>

## Ejemplos Prácticos

### Sistema de Calificaciones

<Code
  code={`Function ObtenerLetra(nota As Double) As String
    ' Convierte número a letra
    Select Case nota
        Case 90 To 100: ObtenerLetra = "A"
        Case 80 To 89:  ObtenerLetra = "B"
        Case 70 To 79:  ObtenerLetra = "C"
        Case 60 To 69:  ObtenerLetra = "D"
        Case Else:      ObtenerLetra = "F"
    End Select
End Function

Sub ProcesarCalificaciones()
Dim i As Integer
Dim nota As Double

    ' Procesar notas de la columna A y poner letras en columna B
    For i = 1 To 10
        If IsNumeric(Range("A" & i).Value) Then
            nota = Range("A" & i).Value
            Range("B" & i).Value = ObtenerLetra(nota)
        End If
    Next i

End Sub`}
lang="VBA"
title="Sistema de calificaciones"
/>

### Calculadora de Nómina

<Code
  code={`Function CalcularSalarioNeto(salarioBruto As Double, Optional deducciones As Double = 0) As Double
    Dim impuestos As Double
    Dim salarioNeto As Double
    
    ' Calcular impuestos (ejemplo: 15%)
    impuestos = salarioBruto * 0.15
    
    ' Calcular salario neto
    salarioNeto = salarioBruto - impuestos - deducciones
    
    CalcularSalarioNeto = salarioNeto
End Function

Sub GenerarNomina()
Dim i As Integer
Dim salarioBruto As Double
Dim deducciones As Double

    ' Procesar nómina para empleados en filas 2-11
    Range("D1").Value = "Salario Neto"  ' Encabezado

    For i = 2 To 11
        salarioBruto = Range("B" & i).Value     ' Salario bruto en columna B
        deducciones = Range("C" & i).Value      ' Deducciones en columna C

        ' Calcular y poner salario neto en columna D
        Range("D" & i).Value = CalcularSalarioNeto(salarioBruto, deducciones)
    Next i

End Sub`}
lang="VBA"
title="Calculadora de nómina"
/>

<Aside type="tip">
  Las funciones bien diseñadas hacen tu código más fácil de entender, mantener y
  reutilizar.
</Aside>
