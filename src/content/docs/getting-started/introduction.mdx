# ¿Qué es VBA?

**VBA (Visual Basic for Applications)** es un lenguaje de programación que permite automatizar tareas en Excel.

En lugar de hacer clic manualmente 50 veces para formatear un reporte, escribes un código que lo haga automáticamente.

## Ejemplo Real

**Sin VBA:** Abrir 10 archivos, copiar datos manualmente, formatear, hacer gráficos. **Tiempo: 3 horas.**

**Con VBA:** Clic en un botón, todo se hace automáticamente. **Tiempo: 2 minutos.**

<Code
  code={`Sub GenerarReporte()
    ' Abrir archivos automáticamente
    ' Procesar datos
    ' Crear gráficos
    ' Guardar resultado
End Sub`}
