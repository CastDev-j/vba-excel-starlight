Vamos a crear una macro que escriba "¡Hola Mundo!" en la celda A1 y la formatee automáticamente.

## Crear la Macro

<Steps>

1. **Abrir Editor VBA**

   - Presiona `Alt + F11`

2. **Insertar Módulo**

   - `Insert` → `Module`

3. **Escribir el código**
   - Pega el código en el módulo

</Steps>

<Code
  code={`Sub HolaMundo()
    ' Escribir texto en A1
    Range("A1").Value = "¡Hola Mundo!"
    
    ' Formatear la celda
    With Range("A1")
        .Font.Bold = True
        .Font.Size = 14
        .Interior.Color = RGB(255, 255, 0)  ' Amarillo
    End With
    
    ' Mensaje de confirmación
    MsgBox "¡Tu primer programa VBA funciona!", vbInformation
End Sub`}
  lang="VBA"
  title="HolaMundo.bas"
/>

## Crear un Botón

Para que otros usuarios ejecuten tu macro fácilmente:

<Steps>

1. **Ir al Developer Tab**

   - Clic en `Insert` → `Button (Form Control)`

2. **Dibujar el botón**

   - Arrastra en la hoja para crear el botón

3. **Asignar macro**

   - Selecciona `HolaMundo` de la lista
   - Clic `OK`

4. **Personalizar texto**
   - Clic derecho → `Edit Text`
   - Escribe: "Ejecutar Hola Mundo"

</Steps>

<Aside type="tip">
  Ahora cualquier usuario puede ejecutar tu macro con solo hacer clic en el
  botón.
</Aside>

## Mejorar el Programa

Versión más completa con validación:

<Code
  code={`Sub HolaMundoMejorado()
    ' Limpiar contenido anterior
    Range("A1").Clear
    
    ' Verificar si A1 está vacía
    If Range("A1").Value = "" Then
        Range("A1").Value = "¡Hola Mundo VBA!"
        
        ' Formato profesional
        With Range("A1")
            .Font.Name = "Arial"
            .Font.Bold = True
            .Font.Size = 16
            .Font.Color = RGB(0, 0, 255)      ' Azul
            .Interior.Color = RGB(240, 240, 240)  ' Gris claro
            .Borders.LineStyle = xlContinuous
        End With
        
        MsgBox "Programa ejecutado correctamente"
    End If
End Sub`}
  lang="VBA"
  title="Versión mejorada"
/>

## Errores Comunes

<CardGrid>
  <Card title="Macro no aparece" icon="error">
    **Causa**: Archivo no guardado como `.xlsm`
    
    **Solución**: `Guardar como` → `Excel Macro-Enabled Workbook`
  </Card>

  <Card title="Error de ejecución" icon="warning">
    **Causa**: Hoja protegida o celda bloqueada
    
    **Solución**: Desproteger hoja antes de ejecutar
  </Card>
</CardGrid>

## Guardar tu Trabajo

  **Importante**: Debes guardar como `.xlsm` para conservar las macros.
</Aside>

1. `Archivo` → `Guardar como`
2. Tipo: `Excel Macro-Enabled Workbook (*.xlsm)`
3. Nombra tu archivo: `Mi_Primer_VBA.xlsm`

</Steps>
