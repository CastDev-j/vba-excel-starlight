Para programar en VBA necesitas habilitar la **pestaña Desarrollador** en Excel.

## Habilitar Developer Tab

<Steps>

1. **Abrir Opciones**
   - `Archivo` → `Opciones`

2. **Personalizar Cinta**
   - Selecciona `Personalizar cinta de opciones`
   - Marca la casilla `Developer`
   - Clic `Aceptar`

</Steps>

## Configurar Seguridad

<Steps>

1. **Trust Center**
   - `Archivo` → `Opciones` → `Trust Center`
   - `Trust Center Settings...`

2. **Macro Settings**
   - Selecciona `Disable all macros with notification`

</Steps>

<Aside type="tip">
Esta configuración te preguntará antes de ejecutar macros, balanceando seguridad y funcionalidad.
</Aside>

## Guardar Archivos con Macros

**Formato requerido**: `.xlsm` (Excel Macro-Enabled Workbook)

<Steps>

1. `Archivo` → `Guardar como`
2. Tipo: `Excel Macro-Enabled Workbook (*.xlsm)`

</Steps>

## Problemas Comunes

<CardGrid>
  <Card title="Developer Tab no aparece" icon="error">
    Reinicia Excel después de habilitar la opción
  </Card>

  <Card title="Macros no se ejecutan" icon="warning">
    Verifica que el archivo sea `.xlsm` y permite macros cuando se solicite
  </Card>
</CardGrid>
